The product

A desktop browser built around Servo.

Servo provides the web engine. GalileoEngine connects it to the rest of the browser, and Galileo Browser is the interface people will eventually use.

01

Desktop first

We are focusing on the tabs, windows, profiles, settings, downloads, and platform integration expected from a desktop browser.

02

Still early

There is no public release or recommendation for everyday browsing. Compatibility and security work are still in progress.

03

One shared foundation

Engine changes, browser features, and release work all stay connected through GalileoEngine.
