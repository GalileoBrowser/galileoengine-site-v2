Platform / 01

Build the browser. Keep shared work upstream.

GalileoEngine owns the browser work around Servo: the desktop shell, the user experience, the quality gates, and the route to a release that can be trusted.

The foundation

Servo supplies the engine. GalileoEngine supplies the product discipline.

Keeping that distinction explicit lets the project remain useful to upstream Servo while giving GalileoEngine a clear responsibility: turn engine capability into a dependable desktop browser rather than simply rename a test shell.

What GalileoEngine owns

The work people will actually feel.

01

Browser shell

Windows, tabs, navigation, settings, profiles, history, downloads, permissions, and recovery form one coherent desktop experience.

02

Compatibility method

Standards suites, reference-browser comparisons, and reproducible real-site journeys turn compatibility into evidence rather than marketing.

03

Release qualification

Security, privacy, accessibility, performance, packaging, and update behaviour require gates before the project makes consumer promises.
