Current work

Start with a baseline. Earn every next step.

GalileoEngine is in its bootstrap and compatibility-baselining stage. The order is deliberate: understand the foundation, build the browser layer, then qualify it for a public release. Galileo Browser is not ready for everyday or security-sensitive browsing yet.

The platform

A clear boundary between foundation and product.

Servo is the web engine underneath. GalileoEngine is the browser platform being built around it: the desktop shell, the release discipline, the compatibility work, and the foundations Galileo Browser will use.

What GalileoEngine owns

A foundation needs a browser layer and proof.

These are the responsibilities that turn a web engine into a product. Each one has to be understood and tested before it becomes a promise.

01

A shared foundation

Servo is the engine base. Improvements that benefit the foundation belong upstream whenever possible.

02

A browser layer

Tabs, profiles, permissions, downloads, recovery, and desktop integration are treated as essential product work.

03

Proof before release

Compatibility, security, privacy, accessibility, stability, and packaging need evidence before any everyday-use claim.
