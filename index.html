Open source, accelerated.

We are a small team from Europe that uses AI to critically accelerate the development of open-source software. We prioritize security and features. Our first project is a web browser engine and a web browser — Galileo Engine and Galileo Browser — forked from Servo, an existing project. The target: full completion in months, not years.

Where we start

First, the praise. It is earned.

Our first project stands on a browser engine that is more than a decade old. This is the lineage, in order — and the one policy that shapes how we work.

2012 / the start

Mozilla Research starts Servo.

A browser engine in Rust, with a real rendering pipeline, serious standards work, and an architecture built to be embedded and extended.

2013–2026 / the long build

The open-source community carries it.

Maintainers — later with the Linux Foundation — turn Servo into a serious, embeddable engine. Browsers have been built on it for years; the work is real.

26 Jul 2026 / the fork

We fork it — and accelerate.

Galileo Engine and Galileo Browser take the same foundation, with AI carrying the volume and humans holding every gate — aimed at full completion in months, not years.

Servo does not accept AI-generated contributions — and that is a fair rule: it protects maintainers from code nobody can explain, test, or defend. Galileo is the other side of the same question. A small team uses AI to generate the volume, and the volume has to earn its place — with tests, retained evidence, and human review. We started with a browser because the web needs one now more than ever: a browser you can actually own, whose rules you can read, whose ad-blockers stay yours. If the method works here, it applies to whatever deserves to move next.
