Building a browser on Servo.

GalileoEngine is the Servo-based engine layer behind Galileo Browser. We are turning Servo’s development shell into a desktop browser, one tested piece at a time.

Where we are now

It builds and runs. It is not ready for daily use.

We can build the current desktop shell and test selected browsing tasks. Compatibility, security, accessibility, packaging, and updates still need substantial work before we can offer a public release.

How the project fits together

Servo provides the engine. We build the browser around it.

Servo, GalileoEngine, and Galileo Browser are three parts of the same technical path. Each has a different job.

What we are working on

The work between Servo and a usable browser.

Our job is to connect the engine to a complete desktop experience and test the result honestly.

Roadmap

Where we go from here.

The next steps move from a reproducible development build toward a secure, accessible, maintainable browser.

  1. Now

    Foundation & browser baseline

    Reproducible builds, a clear capability inventory, and dependable core checks.

    In progress
  2. Next

    Compatibility & hardening

    Broader standards coverage, real-site reliability, accessibility, privacy, security, and media support.

    Planned
  3. Then

    Packaging & release preparation

    Installers, updates, recovery, stability, performance, and release checks.

    Later

The product

Galileo Browser is what people will use.

GalileoEngine does the engine work underneath. Galileo Browser turns it into a desktop experience with tabs, profiles, settings, downloads, and the other parts people expect.

Galileo Browser
