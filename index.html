A browser built on evidence.

Volt is the visual identity for the Stepper Browser codebase: an experimental Servo-based desktop browser whose shell, compatibility work, and release gates are tracked with retained repository evidence.

What the shell inventory actually records

  • Top menus and a toolbar with Back, Forward, Reload, Home, address/search, preferences, and Settings.
  • Tab selection and closing, plus new-tab and new-window actions.
  • A persistent Stepper settings page, internal status pages, and first-run onboarding.
  • Persistent visit ranking and visible address-bar suggestions.
Evidence scope · observed-partial

Volt is not ready for everyday or security-sensitive browsing. The current fork still runs Servo's servoshell, retains many upstream names, and has not passed Volt-specific security, compatibility, accessibility, packaging, or release qualification.
