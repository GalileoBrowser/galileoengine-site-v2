From Servo to Galileo

The foundation comes first.

Galileo does not begin from a blank file. It begins with Servo and more than a decade of work by Mozilla Research, maintainers, and the open-source community.

2012 / the start

Mozilla Research starts Servo.

A browser engine in Rust, with a real rendering pipeline, serious standards work, and an architecture designed to be embedded and extended.

2013–2026 / the long build

The community carries it forward.

Maintainers — later with the Linux Foundation — develop Servo into a serious embeddable engine. Galileo inherits that work and credits it directly.

26 Jul 2026 / the fork

Galileo takes a different branch.

Galileo Engine develops that foundation toward a desktop product. The team owns the review, testing, and every claim made about the result.

Where the work stands

Development, with the gates still open.

The current build is useful for engineering and testing. Compatibility, security, reliability, and packaging still have to pass before Galileo Browser can be offered as an everyday browser.
