About

The browser and its engine.

Volt is the visual identity used by this website. The repository and current source still name the product Stepper Browser, while Servo remains the engine and embedding API. The distinction is explicit so branding never masquerades as completed product work.

A thin fork with clear boundaries

Internal crates and engine symbols are not renamed merely for branding — that reduces breakage and makes upstream merges and contributions practical.

Fixes go home to Servo

Generally useful engine work is written as upstream-quality Servo changes and proposed upstream first, or in parallel. Volt-only product code stays behind clear shell, service, and branding boundaries.

Security

Do not use this build to protect sensitive data

A browser should not be called production-ready until its threat model, sandbox, dependency response, signing, update path, privacy behavior, and security reporting process have been audited. Those are release blockers in the roadmap.

Security problems inherited from Servo should be reported privately through Servo's security advisory form. A separate private Volt reporting channel will be established before public alpha distribution.
