Project status

Where the project stands today.

GalileoEngine builds and selected browser tasks work, but Galileo Browser is not ready for everyday or security-sensitive browsing.

Project stageFoundation & compatibility baseline

We are making builds repeatable and documenting what the current browser can do.

Engine baseBuilt on Servo

GalileoEngine starts with Servo’s capabilities and limitations, then adds our browser integration work.

Release statusNo public release

There is no installer or supported build for everyday use.

Desktop productGalileo Browser

This is the user-facing browser we are building on GalileoEngine.

What that means

Useful development progress, not a finished browser.

Current builds and focused tests help us find problems and track progress. They do not prove that the browser works across the wider web.

We will publish broader claims only when we have repeatable results to support them.

What comes next

Follow the work, not a guessed release date.
