The honest answer

It is moving quickly because the hard parts are visible.

Current work includes browser chrome, profiles, private browsing, media, native content blocking, developer tools, an extension runtime that runs Manifest V2 and V3 entrypoints, the official Cloudflare Turnstile canary (3/3 modes), and a bounded Phase 0 test shard.

Those are valuable engineering milestones. They are not proof that hostile pages are isolated, that the browser is fast, that all websites work, or that an installer can update safely.

Status rule

We do not turn inherited capability into a Galileo guarantee.

Every public claim should point to a focused test, a retained artifact, or a bounded journey. If the evidence only says “the API exists,” the status stays conservative.
