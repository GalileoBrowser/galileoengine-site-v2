About Galileo

Build the browser. Keep the work open.

Galileo is an open-source browser project built in Europe. We start from Servo, add the product work needed around it, and publish evidence before making claims about readiness.

The project

One foundation. Two Galileo layers.

These names describe different responsibilities. Keeping them separate makes the project easier to understand and the engineering claims easier to verify.

Upstream foundation

Servo

The Rust browser engine supplies rendering, layout, and web-platform work. Galileo inherits that foundation and credits it directly.

Engineering layer

Galileo Engine

The accelerated fork and integration layer: compatibility work, media, extensions, product plumbing, and the tests around them.

User product

Galileo Browser

The desktop browser people will eventually use. It remains in development and is not presented as ready for everyday browsing.

Why Galileo exists

Browser work should remain inspectable.

A browser sits between a person and almost everything they do online. That makes ownership, compatibility, security, and long-term maintenance more important than a polished demo.

AI helps a small team carry more implementation work, but people still choose the direction, review the changes, run the tests, and own every public claim. Speed is useful only when the evidence keeps up.

Where it stands

Useful progress. Not a finished browser.

The current build is for development and testing. Compatibility, security qualification, packaging, and release readiness still have open gates.

The roadmap is the source of truth.

Current capabilities, measured evidence, known limitations, and the next release gates are kept together on the Roadmap.
