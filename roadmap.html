Roadmap / snapshot 18 Aug 2026

A browser is a sequence of gates.

The browser already works enough to be measured. This page shows what is measured, what is next, and the order we refuse to skip: compatibility first, then security, then speed, then release. AI compressed the writing; it did not skip the proving.

What is true today

The browser works. Gently.

It opens pages, keeps tabs and profiles, runs private mode, plays media, executes reviewed extensions, and passes its own test shards. “Gently” is the whole sentence: broad compatibility, process isolation, speed, and packaging are not qualified yet, and nothing on this page claims otherwise.

The gates, in order

Compatibility first. Security second. Speed third.

Stages overlap, but claims do not. An incomplete security or packaging gate stops a public browser even if a demo looks good.

  1. 01

    Web compatibility

    The sites you actually use must load, script, and paint — measured with Web Platform Tests, real-site journeys, and Firefox/Chrome comparisons. The longest bar, so it comes first.

    current
  2. 02

    Security

    Process isolation, sandboxing, origin identity, private data, crash recovery, secure defaults. A page is an attacker; we design like it.

    next
  3. 03

    Speed & memory

    Startup, navigation, rendering, and memory budgets on pinned reference hardware. Fast is a number we publish, not a feeling we describe.

    open
  4. 04

    Extensions

    Manifest V2 kept, a real Chrome and Firefox API subset earned package by package, and the native Galileo format — with uBlock Origin passing as the proof.

    open
  5. 05

    Release

    Installers, signing, updates, rollback, and the 72-item public Linux release contract. Boring on purpose; none of the earlier gates mean anything without it.

    later
  6. 06

    The rename

    When the browser engine is genuinely Galileo's own — names, product services, security model — the rename finishes and we maintain our own path, with the history kept visible.

    future

Extensions / the runway

Useful first. Broad later.

Ad blockers are not a side quest — they are the test case. When Manifest V3 made the extensions people rely on hard to ship, the biggest ad-blocker in the world left the biggest store. Galileo is building the other shape: Manifest V2 kept, Chrome and Firefox API surfaces earned package by package, and a native Galileo format for capabilities we can design cleanly ourselves. The end state is simple: the extensions you already rely on in Chrome or Firefox work in Galileo — the important ones, fully — or the native format covers what they do.

The timeline

Months, not years.

Browser work has historically taken teams of hundreds a decade. AI did not remove the testing — the evidence still has to be earned, line by line — but it removed most of the writing, and that is where the years used to go. Our honest expectation is a daily-driver Linux build in months, not a decade.

The public inventory is the check on our optimism: every bar you see can be re-derived from the repository, so you can watch the estimate earn itself — or watch us wrong.

The promise

We will publish the missing bars too.

If security, speed, or compatibility cannot be measured yet, this page says “not measured.” The browser is only ready when the evidence is stronger than the excitement.
