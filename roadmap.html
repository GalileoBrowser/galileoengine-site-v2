Roadmap / forked 26 Jul 2026

A browser is a sequence of milestones.

The roadmap starts where the code started: the fork, 26 July 2026. What is done is dated from the git history, and what is not done is named. The order never changes — compatibility first, then security, then speed — and the timeline is months, not years.

The road / fork → release

From the fork to the first release.

The dates on the finished rows come from the commit history of GalileoEngine, not from memory. The rest are named, and they will not move quietly.

  1. 01

    The fork

    26 July 2026 — Galileo starts where Servo ends: a 15.2-million-line snapshot, a new clock, a public repository. Everything after this commit counts as work.

    done · 26 Jul 2026
  2. 02

    Cloudflare Turnstile

    The official Turnstile canary passes in all three modes — always-pass, always-fail, forced-interactive — headless and headed, with the parity evidence refreshed on 6 Aug. Production challenges remain Cloudflare's decision; we do not fake fingerprints to pass them.

    done · 01 Aug 2026
  3. 03

    YouTube, working

    Media Source Extensions unblocked from day one, then qualified on 14 Aug: unattended YouTube playback, cold start, clock stalls, and replay — with diagnostics that survive the hard pages.

    done · 14 Aug 2026
  4. 04

    Extensions

    The current frontier, since 29 July and 180 commits in: Manifest V2 and V3 entrypoints, permission review, native request blocking, content CSS — and the road to uBlock Origin. When it works, the pre-alpha ships.

    now · in progress
  5. 05

    Pre-alpha release

    The first build anyone can install and try, shipped the moment extensions work. Explicitly labelled pre-alpha: usable for exploration, not for daily driving.

    next · soon
  6. 06

    Google and Facebook login

    The sign-in flows that break new browsers first: OAuth redirects, third-party cookies, popups, and consent walls — working on the two networks everyone tests with.

    open
  7. 07

    Alpha release

    A complete, installable browser across the core loop — browse, tabs, profiles, media, extensions, recovery — with the 72-item public Linux release contract tracked in public.

    open
  8. 08

    Beta — full website compatibility

    The sites you actually use, measured rather than sampled: Web Platform Tests at scale, real-site journeys, and Firefox/Chrome comparisons until the gaps stop mattering.

    open
  9. 09

    Release candidate 1

    Security and everything the inventory still shows as open: process isolation, threat model, speed and memory budgets, packaging, and the long tail of missing features.

    open
  10. 10

    Release

    When RC1 is clean: version 1.0, signed updates, and the browser engine completes its rename to Galileo.

    future
