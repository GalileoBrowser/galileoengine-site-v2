Beyond the README

The architecture is already much larger.

These are source-level observations at the reviewed checkpoint. They show where the project has grown without pretending every path is qualified.

01 / product state

The shell owns durable browser data.

Profiles, history, bookmarks, settings, favicons, and content blocking now have dedicated Rust stores. Tabs, windows, private state, recovery, downloads, and permissions are connected at different levels in the shell.

02 / extension runtime

Extensions are a subsystem, not a placeholder.

Archive, store, and runtime paths exist, with separate modules for actions, messaging, ports, storage, and tabs. Reviewed Manifest V2 packages and the uBlock Origin compatibility gate exercise real browser-owned code.

03 / engine + tools

The work reaches below the browser chrome.

Changes extend into script and Web APIs, constellation sandboxing, DevTools storage and network actors, Android product surfaces, and reproducible pre-alpha receipt and smoke tooling.

The status boundary

Code exists. Qualification still has to catch up.

The project is no longer a thin shell. Browser state, extensions, media, developer tooling, security boundaries, Android work, and release tooling all have substantial implementation behind them.

That still does not prove hostile-page isolation, broad website compatibility, production performance, safe updates, or cross-platform release quality. The latest hosted jobs produced no step-level evidence, so this page does not call the current head qualified.

There is no public Galileo Browser release yet, and the current build is not recommended for everyday or security-sensitive browsing.

    Verified lineage: A full-history review records 93d8f85503e0 from 24 July as the earlier source base. The current hosted repository begins with the standalone import, so the evidence record preserves that provenance separately.

    Progress since the import: At the reviewed head 99af1539f340 on 30 August, 5,099 commits follow the import. That is a source-history count, not a quality score; the measured and qualified results are recorded elsewhere on this page. Inspect the lineage record.

    done · 26 Jul
  2. 02

    Cloudflare Turnstile

    1 August 2026. The official dummy-key canary completed Cloudflare's always-pass, always-fail, and forced-interactive modes: 3/3 headless and 3/3 headed, with the documented callbacks, failure code, and dummy token.

    Retained revalidation: The three controlled modes passed again on 4 August and on the rebuilt medium profile on 6 August. The 6 August checkpoint also retained 127/127 expected results in the selected Galileo regression suite. These are bounded fixtures, not a claim that every production challenge will clear.

    Source progress through 30 August: A local cross-origin click-delivery probe was added on 9 August to distinguish normal input delivery from label-to-control forwarding without contacting Cloudflare. The 14 August integration then expanded the parity probe with WebRTC and offline-audio diagnostics. This improves investigation depth; it is not a newer production clearance result.

    Open boundary: The reviewed production capture reached Cloudflare's remote /pat risk decision and received HTTP 401. Galileo does not replay challenge material, synthesize tokens, or spoof browser fingerprints; production acceptance remains Cloudflare's decision.

    last run · 06 Aug
  3. 03

    YouTube, working

    Last comparable runs · 14 August 2026. A clean-profile, no-WebDriver journey opened YouTube, searched, entered a real non-ad result, selected HD720, and completed 5/5 seeks. The retained run recorded 94.14 seconds of media progress, 65.25 seconds buffered ahead, and no page, media, or browser-panic errors.

    Second retained run: After the unattended harness was hardened, a fresh profile completed another home-to-watch journey and 3/3 seeks, with 119.75 media seconds, 67.8 seconds buffered ahead, and no page, media, or panic errors.

    The probe also found a real limit: Replaying three exact-build reports showed no clock stalls in runs one and three, but isolated a 4.056-second freeze in run two while the video was ready, unpaused, and buffered. The milestone proves bounded playback; it does not claim stall-free YouTube compatibility.

    Source progress through 30 August: The playback path gained stricter MSE initialization and mutation ordering, seek and replay liveness work, bounded append memory, safer GStreamer setup and teardown, and real pitch preservation through preservesPitch. Adjacent media work added Android Media Session handling and verified slices of raw VideoFrame, WebCodecs copy and transfer, and encoded chunk contracts.

    Current boundary: At the 30 August source review, those later changes clearly expanded the media foundation, but no newer comparable sustained YouTube run was retained. The 14 August evidence is a controlled test result, not the date when development stopped.

    last run · 14 Aug
  4. 04

    Baseline and product shell

    Implementation now spans Web APIs, networking, media, DevTools, and dedicated profile, history, bookmark, settings, favicon, and content-blocking stores. Android also has browser-specific history, bookmarks, downloads, modes, themes, and permission work.

    Progress since then: Extension archive and runtime paths became dedicated subsystems, Android gained media-session work, and deeper shell paths now carry more of the browser's durable state and product behaviour.

    now · expanded
  5. 05

    Security foundation

    Sandbox process work, origin and cookie boundaries, permission checks, private partitions, and fail-closed validation are active in code. A complete threat model, process-isolation qualification, signing, and update security remain release gates.

    Progress since then: Cookie partition and expiry evidence, origin-and-mode Android permissions, private extension-resource contexts, host-permission scope, and additional fail-closed protocol and network bounds now make those areas more concrete. The open release gates remain open.

    now · open gate
  6. 06

    Extensions and ecosystem

    The Manifest V2 runtime, reviewed packages, permissions, content scripts, storage, messaging, tabs, ports, and network interception are real code paths. uBlock Origin 1.73.0 passed a bounded package gate; full compatibility is not claimed.

    Progress since then: The runtime, store, and archive paths expanded; actions, context, messaging, ports, storage, and tabs were split into dedicated modules; receiver-liveness, failure handling, content DOM helpers, download-danger lifecycle, and hot-path performance were strengthened.

    now · qualified slices

    Progress since then: The release path now also checks licences and credentials and binds its receipts more tightly to the source revision. Those safeguards improve the engineering package; they do not turn it into a public release.
