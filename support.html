Contribute / open source

Help move the project forward.

Galileo is an open-source project. Code, failing tests, careful review, useful disagreement — and, eventually, funding for compute and infrastructure — can all make the work better.

01 / contribution

Contribute where the work is public.

Start with a bounded issue, reproduce the failure, and attach the evidence. The public organization repositories ↗ are the right place for code that is open today; core engine contributions begin when that repository is opened.

02 / contribute signal

Test the edges

Try real sites, extensions, media, profiles, and accessibility flows. A precise failure report saves more time than a polished demo because it gives us something concrete to fix.

03 / contribute ideas

Join the discussion

The public conversation happens in the project discussions on GitHub ↗; the site newsletter keeps the maintainer announcement record.

04 / contribute time

Help choose the next tool

The browser is the first proof. If you care about creative software, email, or other missing open-source tools, tell us which gap would matter most to you.

The honest budget

AI is fast. It is not free.

Every line this project writes costs tokens, and tokens cost money. AI removed the bottleneck from writing — it did not remove testing, evidence, or human review, and that is where the real time still goes. Today the compute is funded out of our own pockets, and it is the single biggest throttle on the pace: the method works, but we are rationing it.

When we open a funding channel, it will buy speed, not features, and not control: compute for generation and test, reference hardware for compatibility, and release engineering. Support would not make us louder. It would make us faster — and the reporting on where the money went would be public, the same way the code is.

Funding status

We are not accepting money yet.

We will publish the organization, the payout route, sponsorship tiers, and reporting rules before opening a funding channel. GitHub Sponsors is pending; until then, code, careful feedback, and discussion are the most useful contributions — and they cost nothing.

If funding opens

Fund the work without buying control.

Money should buy more measurement and maintenance, not a louder promise.
