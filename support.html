Where funding would go

What sponsorship would pay for.

Before sponsorship opens, we will publish who receives the money, how spending is approved, and how we report it.

01

Build & test infrastructure

CI capacity, test services, and the storage needed to keep results reproducible.

02

Compatibility & quality

Test hardware, platform coverage, and time to investigate browser failures properly.

03

Release services

Domains, distribution, code signing, security review, and release documentation.

04

Engineering time

Implementation, review, documentation, contributor support, and routine maintenance.

Stewardship

Simple rules for handling project money.

Use the organization

The recipient and payout route will be public before we accept any payments.

Report what we spend

We will publish useful summaries of income, expenses, and important changes to the plan.

No paid control

Sponsorship will not buy equity, technical control, or a promised release date.
