Phase 0 bootstrap & compatibility baselining

Where the project actually is.

The repository currently inherits Servo's capabilities and limitations. Servo's own documentation describes servoshell as a test browser rather than a fully fledged one.

At commit af08a060, the generated feature matrix contains 68 rows: 52 are observed-partial, seven are unmeasured, and none is automation-qualified. Those labels describe evidence scope, not production support.

The shell inventory records real menus, navigation controls, tabs, persistent settings, internal pages, onboarding, and address suggestions. Headed keyboard/focus verification, complete workflows, security qualification, packaging, and the 72-item public Linux release contract remain open.
